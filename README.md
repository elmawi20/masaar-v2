# نظام عيادة مسار — Masaar Clinic System
## المرحلة 2: ماكينة الجودة والبنية التحتية (Stage 2 — Quality Machine)

مرحباً بك في **نظام مسار**، النظام السحابي المتخصص لإدارة عيادات ومراكز العلاج الطبيعي والتأهيل الحركي والتغذية العلاجية في مصر.

تم في هذه المرحلة (المرحلة 2) بناء **ماكينة الجودة والبنية التحتية البرمجية** بالكامل، لتكون الأساس المتين والآمن الذي ستُبنى عليه جميع شاشات وميزات العيادة في المرحلة 3.

---

## 🚀 البدء السريع وتشغيل النظام (Quick Start)

### 1. تشغيل واجهة النظام على جهازك
افتح موجه الأوامر (Terminal أو PowerShell) في مجلد المشروع، ثم اكتب الأمر التالي:
```bash
npm run dev
```
بمجرد ظهور رسالة `Ready`، افتح المتصفح على الرابط التالي:
👉 **[http://localhost:3000](http://localhost:3000)**

ستظهر لك الواجهة الرئيسية للنظام باللغة العربية (RTL) تلقائياً، ويمكنك استعراض شاشات النظام، وتبديل المظهر (فاتح / داكن)، وتغيير اللغة (العربية / الإنجليزية)، ومعاينة القوائم المخصصة لكل دور وظيفي.

## 🧪 تشغيل الاختبارات الآلية (Running Tests)

يحتوي النظام على شبكة أمان واختبارات آلية تغطي جميع القواعد وقاعدة البيانات والصلاحيات بنسبة 100%:

### 1. تشغيل جميع الاختبارات (الوحدات + قاعدة البيانات)
```bash
npm run test
```
*يقوم بتشغيل 305 اختباراً آلياً يتأكد من الصلاحيات، انتقالات الحالات، ومنع التعارض الزمني في الحجوزات، ومنع تكرار الهواتف، وحظر حذف المرضى أو سجلات التدقيق.*

### 2. تشغيل اختبارات الوحدات السريعة فقط
```bash
npm run test:unit
```

### 3. التحقق من تغطية قواعد وثيقة المواصفات (199 قاعدة)
```bash
npm run test:coverage
```
*يقوم بفحص جميع القواعد الـ 199 المسجلة في وثيقة المواصفات، وتوضيح القواعد المغطاة برمجياً حالياً والقواعد المجدولة للمرحلة 3.*

### 4. التقاط وفحص لقطات الشاشة لجميع الشاشات والأجهزة
```bash
npm run test:e2e
```
*يقوم بفتح متصفح آلي والتقاط 12 لقطة شاشة للشاشات الثلاث (الهاتف 390px، التابلت 820px، الكمبيوتر 1440px) باللغتين العربية والإنجليزية وبالوضعين الفاتح والداكن وحفظها في مجلد `artifacts/screenshots`.*

## 📦 ملء قاعدة البيانات بالبيانات التجريبية (Database Seeding)

لتعبئة قاعدة بيانات التطوير (`masaar_dev`) ببيانات مصرية تجريبية واقعية:
```bash
npm run db:seed
```

### ماذا يضيف هذا الأمر؟
1. **بيانات العيادة ومواعيد العمل:** مواعيد العيادة من السبت إلى الخميس من 9 صباحاً حتى 9 مساءً، والجمعة عطلة.
2. **حسابات العاملين للأدوار الخمسة:**
   - **المالك (Owner):** `owner@masaar.local` (د. أحمد المعوي)
   - **مدير العيادة (Manager):** `manager@masaar.local` (منى حسن)
   - **الاستقبال (Receptionist):** `receptionist@masaar.local` (سارة محمود)
   - **العلاج الطبيعي (Physiotherapist):** `physio@masaar.local` (د. عمر طارق)
   - **التغذية العلاجية (Nutritionist):** `nutritionist@masaar.local` (د. نوران علي)
   *(كلمة المرور الموحدة لجميع حسابات التجربة هي: `Password123!`)*
3. **الغرف والأسِرّة:** 3 غرف رئيسية و 4 أسِرّة علاجية وفحص.
4. **أنواع الجلسات:** جلسة علاج طبيعي (45 دقيقة)، استشارة تغذية (30 دقيقة)، كشف وتقييم استشاري (60 دقيقة).
5. **مرضى تجريبيين مصريين:** مرضى بالغين بهواتفهم، وطفل تابع مرتبط بولي أمره.
6. **باقات ومدفوعات وحجوزات:** باقة 12 جلسة، فواتير إلكترونية بأرقام `INV-2026-00001`، وحجوزات مجدولة ومكتملة.

## 🔒 قواعد الأمان والتشغيل المحلي (Safety & Architecture Rules)

1. **تشغيل محلي بالكامل:** يعمل النظام حالياً على جهازك المحلي فقط (`localhost:3000`) دون أي اتصال بخوادم خارجية أو استضافة سحابية.
2. **حظر الحذف النهائي (Zero Hard Delete):** لا يمكن حذف أي مريض أو معاملة مالية نهائياً من قاعدة البيانات؛ جميع العمليات تستخدم التعطيل أو الإلغاء أو الاسترداد المالي مع قواطع حماية مدمجة في PostgreSQL.
3. **سجل تدقيق رقابي غير قابل للتعديل (Append-Only Audit):** كل عملية كتابة في النظام تُسجل تلقائياً في جدول رقابي محمي بقواطع برمجية تمنع تعديله أو حذفه حتى من قِبل المالك.
4. **حماية الهواتف المصرية:** تمنع قاعدة البيانات تسجيل رقم محمول مكرر للمرضى البالغين مع دعم المرضى التابعين (أطفال وكبار سن) برقم ولي الأمر.
5. **منع التعارض الزمني (Exclusion Constraints):** تستخدم قاعدة البيانات تقنية `btree_gist` لمنع الحجز المزدوج لنفس المعالج أو نفس السرير أو نفس المريض في نفس الدقيقة.
